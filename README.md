# Proyecto Final – Data Science 1 - Coderhouse
## Autor: Matías Ghigi

Este repositorio contiene el proyecto final de la materia Data Science 1 de Coderhouse.

### Contenido
- ProyectoParteIII_GHIGI.ipynb  
- movies.csv  

### Descripción
El proyecto incluye:
- Limpieza y exploración del dataset (EDA)
- Ingeniería de variables
- Feature Selection con SelectKBest
- Modelo de regresión Ridge
- Evaluación mediante MAE, RMSE y R²
- Conclusiones finales

### Cómo ejecutar
Simplemente abrir el notebook en Google Colab o Jupyter Notebook y asegurarse de que `movies.csv` esté en el mismo directorio.
